# 写作方法

这个站点的每篇文章遵循同一套结构，专门针对「没有标准答案」的问题。

## 五段式模板

1. **问题** — 什么场景下遇到的，为什么现有资料帮不上。
2. **官方说法** — 教科书 / 文档怎么说（这部分要短）。
3. **失效点** — 官方说法在哪跟现实对不上。
4. **我的决策** — 怎么权衡的，选了什么，放弃了什么。
5. **待验证** — 哪些判断还没被实践验证，留个钩子。

第五段是关键：它逼你承认「我不知道」，而不是假装懂了。

## 怎么写一篇新文章

在 `docs/` 下对应目录新建一个 `.md` 文件，套用上面的结构写。然后去 `docs/.vitepress/config.mjs` 的 sidebar 里加一行链接。本地 `npm run dev` 看效果，`git push` 后自动发布。
